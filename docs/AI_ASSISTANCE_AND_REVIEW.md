# Assistance IA et relecture humaine

Le travail a été développé dans un flux assisté par intelligence artificielle sous la responsabilité de Patrick Royer. Pour la version publique v0.1, Codex a :

- inventorié les sources et les dépendances ;
- recomposé les statistiques depuis le CSV sauvegardé ;
- préparé la source LaTeX et le paquet de diffusion ;
- contrôlé les empreintes, les ZIP et le rendu PDF ;
- préparé les métadonnées GitHub et Zenodo.

Aucun système d'IA n'est présenté comme auteur humain. Aucun établissement, financement, ORCID ou évaluateur humain n'est ajouté par inférence.

Une relecture humaine spécialisée est sollicitée. Elle n'est pas attestée comme réalisée dans cette version.
