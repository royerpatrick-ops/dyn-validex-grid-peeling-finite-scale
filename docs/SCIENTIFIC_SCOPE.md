# Portée scientifique

La note concerne une comparaison numérique moyenne à taille finie pour :

- une forme initiale à symétrie ternaire ;
- deux rayons `R = 256, 512` ;
- trois orientations `0, atan(1/8), pi/4` ;
- trois contractions historiques `0.95, 0.90, 0.85` ;
- une perte sur le coefficient de forme complexe `a3` ;
- 64 nouvelles translations appariées, séparées des 16 unités exploratoires.

Elle ne revendique :

- aucun exposant exact ;
- aucune préférence uniforme selon l'orientation ou la contraction ;
- aucun théorème de convergence ni réfutation asymptotique ;
- aucune nouvelle valeur de pi ;
- aucune validation physique ou générale de la Dynagénèse ;
- aucune relecture scientifique humaine indépendante achevée.

Le point dynagénique et la redéfinition des entités sont hors périmètre. Le dépôt statique C-infini est un travail distinct et n'est pas modifié.
